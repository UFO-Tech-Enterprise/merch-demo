# Merch Demo Product Brief

Merch Demo is a presentation-style demo for a merchandiser mobile app with an admin workspace.

The first screen should be the actual demo surface, not a marketing landing page. The user should be able to switch slides/scenarios, inspect field workflows, and later jump between mobile and admin views.

Core demo slices:

- Field route planning and visit status.
- Store visit checklist, shelf photos, pricing, stock and issue capture.
- Supervisor route/team control for merchandisers.
- KAM self-route and key-client visit flow.

Current role scope:

- Merchandiser.
- Supervisor of merchandisers.
- KAM.

Out of scope for the first deck:

- Any unrelated role flow outside merchandising, supervisor-of-merchandisers and KAM.
- Branded screenshots or mentions of the previous product name.

Design direction:

- Use Ant Design components first.
- Keep custom UI focused on layout, data storytelling and product-specific presentation.
- Keep cards to repeated items and framed tools only.
- Avoid hardcoded component colors; use `src/theme/tokens.ts`.
